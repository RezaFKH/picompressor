# پیکو کمپرسور (Picompressor)

فشرده‌ساز تصویر که کاملاً در مرورگر کار می‌کند. تصویر را انتخاب می‌کنی، فرمت و کیفیت خروجی را تنظیم می‌کنی، نتیجه را کنار تصویر اصلی می‌بینی و دانلود می‌کنی. **هیچ فایلی آپلود نمی‌شود** و پردازش روی دستگاه خودت انجام می‌شود.

## امکانات

- **ورودی:** PNG، JPEG، WebP، GIF و BMP (از GIF متحرک فقط فریم اول ذخیره می‌شود).
- **خروجی:** PNG (بدون افت کیفیت)، WebP و JPEG.
- **کیفیت قابل تنظیم** برای WebP و JPEG با لغزنده و سه پیش‌تنظیم (کم‌حجم ۶۰، متعادل ۸۰، باکیفیت ۹۲). مقدار پیش‌فرض ۸۴ است و تصویر بعد از رها کردن لغزنده دوباره فشرده می‌شود.
- **مقایسه‌ی قبل و بعد** با خط کشیدنی روی خود تصویر.
- **نمایش درصد کاهش حجم** و نوار مقایسه‌ی حجم اصلی و فشرده.
- **کشیدن و رها کردن** فایل در هر جای صفحه.
- **پوسته‌ی تیره و روشن** (پیش‌فرض بر اساس تنظیم سیستم) و رابط راست‌به‌چپ فارسی.
- **واکنش‌گرا** برای دسکتاپ و موبایل.
- **بدون وابستگی و بدون ساخت:** یک فایل HTML به‌همراه فونت‌ها؛ هیچ درخواستی به سرویس بیرونی نمی‌رود.

## اجرا

نیازی به نصب یا ساخت نیست. مخزن را دریافت کن و `index.html` را در مرورگر باز کن:

```bash
git clone https://github.com/RezaFKH/picompressor.git
cd picompressor
# فایل index.html را در مرورگر باز کن، یا با یک سرور ساده:
python3 -m http.server 8000   # سپس http://localhost:8000
```

برای انتشار روی GitHub Pages یا هر میزبان ایستا، فقط `index.html` و پوشه‌ی `fonts/` را کنار هم قرار بده.

## نکته‌ای درباره‌ی PNG

خروجی PNG با رمزگذار خود مرورگر ساخته می‌شود. برای تصاویر کاملاً مات، برنامه خروجی را بدون کانال آلفا می‌سازد که حدود ۱۵ تا ۲۰٪ کوچک‌تر است. با این حال PNG به PNG یا JPEG به PNG ممکن است از فایل اصلی بزرگ‌تر شود. برنامه در این حالت پیام «سنگین‌تر از فایل اصلی» را نشان می‌دهد و WebP یا JPEG را پیشنهاد می‌کند.

## ساختار پروژه

```
index.html        رابط کاربری، استایل و منطق فشرده‌سازی (یک فایل)
fonts/            وزیرمتن و JetBrains Mono (woff2) به‌همراه مجوز هر دو
LICENSE           مجوز MIT
```
